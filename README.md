# TO_DO LIST Terminal

Uma To_Do List simples feita em python que roda no terminal, com funcionalidades de:

- Adicionar tarefas
- Listar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Salvar tarefas em arquivo JSON

## Como rodar

1. Clone o repositório
2. Rode 'python tp_do.py'
3. Divirta-se adicionando e organizando suas tarefas!
